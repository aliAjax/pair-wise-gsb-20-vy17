# 病理外院会诊续作链（hxwl-06）

借片单据、玻片染色版本、视野标注、会诊签发共用一条**只增不改的事件链**，避免玻片归还后旧意见被当成新结论。

## 技术栈

React 19 + Vite + TypeScript + CSS；领域逻辑与 UI 分离，状态持久化到 localStorage。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5106
npm run typecheck
npm run test:smoke # 42 项领域规则冒烟测试
```

## 会诊链规则

| 环节 | 规则 |
| --- | --- |
| 借出 | 开具借片单据的瞬间**冻结玻片染色版本与染色批次**；外院在借出期只能补标注，归还、重染、签发等改动一律拒绝 |
| 标注 | 每条标注记录镜下坐标 `玻片@x,y/倍数`、作者、依据版本（冻结版/当前版） |
| 离线 | 专家离线标注先暂存，回连时按坐标合并：同坐标同文本**本人重传去重、他人合并署名**；同坐标不同文本**同一视野保留两版** |
| 归还 / 重染 / 损坏 | **未签发结论立即失效**并要求在新版本上重算；**已签发意见连同版本/批次保留快照**，不随后续变化改动 |
| 签发 | 同一版本两名专家“同时”提交时**只有一份生效**，先到者签发、后到者冲突拒绝（仅审计留痕）；外院不得签发 |
| 批次写入 | 写操作以“完整会诊批次”提交；第 N 条事件后写入失败时，物化状态停在半截、**完整批次保留**，恢复时回到基线重放整个批次；挂起期间禁止叠加写入 |
| 旧会诊 | 缺玻片版本的历史数据按**借片日期**回填当日或之前最近的染色版本，回填前禁止继续标注 |

## 代码结构

```
src/domain/
  types.ts    领域模型 + append-only 事件 / 批次 / 审计
  logic.ts    纯函数规则：命令 -> 事件[]，事件归约 applyEvent
  store.ts    批次提交、部分失败注入、从完整批次恢复、离线队列
  seed.ts     四条演示链（旧会诊待回填 / 借出中分歧 / 已归还失效+快照 / 待借出）
src/ui/view.ts 视图派生（视野分组、过期判定、指标）
scripts/smoke.ts 领域规则冒烟测试
```

## 演示路径

1. **C-01（旧会诊）**：点“按借片日期回填玻片版本”，看到冻结版本变为借片日前最近的 `HE-v1/B23101`；点“模拟越权”查看拒绝审计。
2. **C-02（借出中）**：视野 A1 已存在两位专家的不同结论（两版并存）；点“模拟双专家同时提交”只一份生效；切到外院身份只能补标注。
3. 打开“离线”开关提交标注 → 关闭离线后在链内“回连：按坐标合并”。
4. 顶栏开启“⚡ 模拟写入失败”，再对借出中的链点“玻片归还”：批次在第 1 条事件（失效）后中断、阶段仍停在借出态，到“事件批次”页点“从完整批次恢复重试”，归还事件补回。
5. **C-03（已归还）**：未签发草稿显示“已失效”，已签发意见在快照区保持签发时的 `HE-v1`；执行重染后需在新版本重算标注才能再签发。
